# ADR-0038: Fresh reported virtual IP comparison entry point

Status: proposed.

The public root/budgets/policies entry point admits no prepared carriers. It owns one fresh fixed GLOBAL VIP source factory call and binds policies with that execution's original envelope/domains.
It invokes the trusted owning checker with the complete sorted original VIP population; source closure, all operand validation and every selector precede findings, including empty policies and unselected cells.
Returned preparation/plan/result objects remain inspectable and are not admission/value seals. The checker retains all original operand/gap evidence and conditional reported semantics.

No parser/Writer replay, raw-row semantic lookup, default report/CLI change or health inference is added. Proof/factory/core dependencies require separate exact-head qualification.
Version, positive anycast, read-scope, explicit absence baseline, full P4/M1/field and P5 acceptance remain unqualified.
