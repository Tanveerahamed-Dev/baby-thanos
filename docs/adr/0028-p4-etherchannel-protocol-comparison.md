# ADR-0028: Source-bound declared EtherChannel protocol pairs

Status: proposed.

`prepare_protocol_comparisons(root, budgets, policies)` owns a fresh fixed STP/EC/HSRP run.
Only root, budgets and typed policies are inputs; Store/plan/index/prepared carriers are not.
Each DECLARED `same_reported_protocol` policy selects two original target/group subjects
on different nodes in one envelope/context; local group numbers never establish peers.
All owners finish; whole-profile Store/Reader/proof and owning EC source checks close
before every plan, including empty policies/unselected subjects. The owner rebuilds protocol/member
states and supplies original canonical targets without parser/Writer replay or admission authority.
Policy bytes/digests/refs remain separate from captures; budgets count registry once with all inputs. Coverage stays open; no findings.
A later checker calls the factory afresh. Fact declarations, profiles, reports and CLI stay fixed.
No mode/default/member/min-links/peer inference, R-ID closure, P4/EX-02/M1/field or P5 acceptance is claimed.
