# ADR-0025: Global displayed-root fact production

Status: proposed.

The named `build_root_observations_global(root, budgets, peers=...)` selects
the fixed STP Root4 declaration before one global parser execution. Typed
application-supplied peers remain opaque. Legacy APIs and profiles stay fixed;
Root4 and legacy share operation/StepId but cannot compile together.

The producer retains the original envelope, requests and parser values.
All capture/owner/registration receipts close before STP materialization.
Each declared subject has four cells in one FactStore. Consumers must close
every peer before estate use. Declared FactReader reads remain controlling.

Owning adapters expose a literal four-fact contract and original row states.
Root identity Known values grant six original spans, all required, with distinct
priority/MAC anchors. Exact integer VLANs exclude bool. Permissions are not
admission. The owning value validator compares all four states with the same
retained execution, including raw text, basis, evidence and Unknown needs.

Priority keeps printed extension bits and zero; MAC preserves printed case.
Missing values stay Unknown. No Root folder report, schema, CLI, intended root,
topology, health, platform qualification, P4 completion, EX-02, M1 or P5 is claimed.
