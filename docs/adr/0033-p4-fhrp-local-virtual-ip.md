# ADR-0033: Local registered reported IPv4 virtual IP

Status: proposed.

The named local API compiles a fixed STATE+VIP FHRP catalogue before one cache-owned parser run.
The old state parser Step/operation stay fixed; a derive Step reads actual STATE and writes only VIP in a separate Store.
Retained request/Capture input custody plus profile/cache/row/column/value closure precedes BOTH writer stages.
Source state rows share the canonical constructor; Known VIP is plain IPv4/raw exact/OBSERVED
from its authenticated VIP column. Printed unknown, absence, damage and uncollected inputs stay Unknown.
All declared metadata/evaluator identities are fixed; readers require declared VIP grants.
Typed catalogues, receipts and results are not admission tokens; callers own raw admission and budgets.

Legacy declarations/profiles/report bytes stay fixed. No global VIP profile/proof index/report/CLI,
version/anycast/read-scope/baseline/intended VIP or health inference is added. Global source-value/
proof/Reader closure and a conditional logical-gateway VIP disagreement check remain required later work.
No R-ID/P4/M1/EX-02/field qualification or P5 acceptance is claimed.
