# ADR-0035: Fixed GLOBAL VIP proof custody component

Status: proposed.

FhrpVipProofIndex accepts the fixed STP/EC/STATE+VIP registration in a trusted application composition.
It closes the original execution/capture ledger and initially exposes the existing five fact scopes.
After those owning facts close, it adds VIP scopes from authenticated original HSRP interface/group/row/VIP columns.
Known evidence requires every owning span and the VIP-column positive anchor; endpoints and neighbors cannot donate proof.
VIP Store owners, exact cells/rows, actual Reader identity and every leaf reference close before the Reader is retained.
The narrow VIP FactRef endpoint expands only bound owning leaves through that Reader; it accepts no caller Store/Reader.

This is proof permission/leaf custody, not whole-run admission, canonical value sealing or general recursive resolution.
The qualified producer supplies canonical values; a fresh fixed whole-source factory and logical VIP check remain required.
Empty scope custody proves neither health nor expected-population closure; no empty-repeat refusal is promised.
Legacy/default/Root profiles and reports stay fixed; no full GLOBAL pipeline, P4/M1/field or P5 acceptance.
