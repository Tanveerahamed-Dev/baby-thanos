# ADR-0039: Bounded explicit HSRP version parser

Status: proposed.

The additive exact show standby all operation preserves explicit header version 1/2 tokens and owning byte spans.
Only a complete allowlisted block, closed by its Group name line, can supply a usable operand.
Every mandatory body category occurs once; unsupported, damaged or unfinished input invalidates the capture.
Detail-category order is flexible until closure; non-VIP details are syntactic consumption, never interpreted state facts.
The Group name is closure only, never interface/group identity evidence.
A canonical IPv4 virtual-address literal in that same block supplies the address-family witness.
Missing version or unknown address-family evidence stays Unknown; group numbers and MAC default prose supply no version.
Duplicate exact interface/group headings, including unknown-family competitors, invalidate the capture conservatively.
Primary pinned output establishes an explicit version-2 format lesson; explicit version 1 is synthetic allowlist coverage only.
The parser owns no Store, source admission, logical binding, finding or health verdict.
Legacy STATE/VIP/default profiles and report bytes stay fixed.
Registered VERSION production, GLOBAL source/proof closure and fresh conditional logical comparison remain required.
No platform/train qualification, P4/M1/field/P5 acceptance or numbered correlation claim is added.
